# Portifolio v2 — Samuel Barbosa

Portfólio profissional de Samuel Barbosa, desenvolvedor full-stack.

## Stack

- React 19 + TanStack Start + TanStack Router
- Tailwind CSS v4
- Motion (Framer Motion) + GSAP
- Shadcn/ui (Radix UI)
- Vite 8 + TypeScript
- npm / Node.js

## Desenvolvimento

Requer **Node.js ≥ 20** e **npm ≥ 10**.

```sh
npm install
npm run dev
```

## Scripts

| Comando           | Descrição                   |
| ----------------- | --------------------------- |
| `npm run dev`     | Servidor de desenvolvimento |
| `npm run build`   | Build de produção           |
| `npm run preview` | Pré-visualização do build   |
| `npm run lint`    | Verificação de lint         |
| `npm run format`  | Formatação com Prettier     |
| `npm test`        | Executa testes (vitest)     |
